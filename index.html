Manual Session Controls (Or Sync automatically via Flowmo):

Connect app.flowmo.io

To auto-detect start, pause (bathroom breaks), and break times directly from app.flowmo.io, copy and run this simple listener in your browser console on the Flowmo tab: 

// Paste in app.flowmo.io Developer Console (F12)
(function() {
  const channel = new BroadcastChannel('flowmo_gcal_sync');
  console.log('✅ Flowmo GCal Sync Bridge Attached!');
  
  let lastState = '';
  setInterval(() => {
    // Detect flowmo timer buttons state
    const playBtn = document.querySelector('button[aria-label*="Start"], button[aria-label*="Play"], .timer-play-btn');
    const pauseBtn = document.querySelector('button[aria-label*="Pause"], .timer-pause-btn');
    const isPaused = document.body.innerText.includes('Paused') || (playBtn && !pauseBtn);
    const isWorking = !!pauseBtn || document.body.innerText.includes('Focusing');

    let state = 'IDLE';
    if (isWorking) state = 'ACTIVE';
    else if (isPaused) state = 'PAUSED';

    if (state !== lastState) {
      lastState = state;
      channel.postMessage({ type: 'FLOWMO_STATE_CHANGE', state: state, timestamp: Date.now() });
      console.log('⚡ Flowmo State Broadcasted:', state);
    }
  }, 1000);
})();

Why "Error 401: invalid_client / no registered origin" happens:

Google OAuth requires that the URL opening the sign-in prompt matches an exact authorized origin URL configured in your Google Cloud Console.

⚠️ You opened this directly as a local file (file://). Google OAuth does NOT support file://. You must serve it via local web server!

Step 2: Run a Simple Local Web Server

Run one of these commands in your terminal in the folder containing this file:

Python: python -m http.server 8000
Node/NPX: npx serve .

Then open http://localhost:8000/flowmo_gcal_sync.html in your browser.

Step 3: Add Authorized Origin in Google Cloud
  1. Go to Google Cloud Console → Credentials.
  2. Click your OAuth 2.0 Client ID (Web application).
  3. Under Authorized JavaScript origins, click + ADD URI.
  4. Paste: http://localhost:8000
  5. Save changes (can take 2-5 mins to take effect).
